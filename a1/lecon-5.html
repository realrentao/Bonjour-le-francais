Leçon 5 · Trouvez l'objet

找出物品

对话 Dialogue

MarcQuel est cet objet ?
这个物品是什么？
LéaC'est un livre.
这是一本书。
MarcEt ça, c'est quoi ?
那这个，是什么？
LéaC'est une clé.
这是一把钥匙。
MarcOù est mon sac ?
我的包在哪儿？
LéaLe voilà, sur la table.
在这儿，在桌子上。

词汇 Vocabulaire

法语音标中文
quel(le) [kɛl]哪个 / 什么
objet [ɔb.ʒɛ]物品
livre [livʁ]书
clé [kle]钥匙
sac [sak]包
table [tabl]桌子
sur [syʁ]在…上
dans [dɑ̃]在…里
un/une [œ̃]/[yn]一个（阳/阴）
voilà [vwa.la]在那儿
où [u]哪里

语法 Grammaire

Articles 冠词
un（阳）/ une（阴）表「一个」；le/la 表「这个/那个」。
un livre / le livre
une clé / la clé
Sur / Dans
表示位置：sur = 上，dans = 里。
sur la table
dans le sac

文化 Culture

Deviner les objets en français renforce le vocabulaire. （用法语猜物品能巩固词汇。）
