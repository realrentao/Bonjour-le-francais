Leçon 29 · Cyberacheteurs

网购一族

对话 Dialogue

LéaLe site sur lequel tu commandes est-il fiable ?
你下单的那个网站可靠吗？
MarcTrès : c'est celui auquel je fais confiance depuis cinq ans.
非常可靠：那是我信赖了五年的网站。
LéaEt les délais de livraison, ils sont respectés ?
送货时限守时吗？
MarcEn général oui, sauf pendant les soldes où tout est saturé.
通常是的，除了打折季一切爆仓的时候。
LéaMoi, je préfère les boutiques où l'on peut essayer.
我更喜欢能试穿的实体店。

语法 Grammaire

Les pronoms relatifs composés 复合关系代词
lequel / laquelle / lesquels / lesquelles，与 à、de 缩合成 auquel、duquel 等，用于指物。
Le site sur lequel je commande est fiable.
Voici le problème auquel je pense.
Où 作关系代词
où 引导地点或时间，替代 dans lequel / auquel。
La boutique où je vais est fermée.
Le jour où il est arrivé.

文化 Culture

法国电商以「 soldes d'hiver / d'été 」法定打折季闻名，一年两次、每次约四周，由法律规定日期，是全年的消费高峰。
