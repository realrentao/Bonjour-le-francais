Mémento grammatical

语法备忘

A2 阶段核心语法点速查。

速查

Passé composé 复合过去时avoir/être + pp : J'ai mangé / Je suis allé(e)
Imparfait 未完成过去时背景/习惯/状态 : Il pleuvait / J'avais faim
Impératif 命令式(tu) Regarde ! / (nous) Regardons ! / (vous) Regardez !
Conditionnel présent 条件式现在时je voudrais / tu pourrais / il faudrait / nous irions
Futur simple 简单将来时je serai / tu feras / il aura / nous ferons / ils auront
Subjonctif présent 虚拟式现在时que je sois / que tu aies / qu'il fasse / que nous ayons
Relatifs 关系代词qui (主语) / que (宾语) / dont (de+qui) / où (地点)
Comparatif 比较级plus ... que / moins ... que / aussi ... que / le/la/les plus ... de
Passif 被动语态être + pp (+ par) : Le livre est écrit par ...
Pronoms 代词 complémentsme/te/le/la/lui/nous/vous/les/leur (COD/COI)
